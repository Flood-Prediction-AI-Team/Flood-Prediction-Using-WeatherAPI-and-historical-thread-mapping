## Project Overview
This project is an end-to-end predictive web application that creatively fuses static historical disaster datasets with live meteorological data to map localized flood threats.

It bridges a custom HTML/CSS/JavaScript frontend with a Python/Flask backend and a machine learning inference engine, calculating real-world geospatial proximity using the Haversine formula.
